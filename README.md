
# CustomerConnect API

A portfolio project demonstrating AI-Driven Development Life Cycle
(AIDLC) governance and hands-on REST API engineering.

## Project Objectives

1. Build a lightweight AIDLC Command Center with human approval
   gates, artifact controls, and measurable delivery evidence.
2. Apply the Command Center to develop a functional customer-facing
   REST API using Python, FastAPI, and SQLite.

## Delivery Roadmap

### Milestone 1 — AIDLC Command Center
- M1.1: Purpose and requirements — Approved
- M1.2: Repository structure and AI operating rules — In progress
- M1.3: Artifact templates, decisions, and KPI logs — Planned
- M1.4: Automated approval validator — Planned
- M1.5: Validation and milestone approval — Planned

### Milestone 2 — CustomerConnect API
- Inception: Business charter, requirements, and backlog
- Construction: Architecture, API contracts, implementation, and tests
- Operations: CI, release readiness, and portfolio evidence

## Technology Direction

- Python, FastAPI, SQLite
- Pytest and HTTPX
- OpenAPI / Swagger UI
- GitHub and GitHub Actions
- Markdown and Mermaid

## Project Guardrails

- Zero-cost tools and infrastructure only
- Synthetic data only; no real patient information
- Human approval before controlled milestone progression
- All implementation and test claims require evidence
- Keep the MVP small, functional, and reproducible

## Current Status

Milestone 1 is in progress. No application implementation
or automated validation has been completed yet.

## Portfolio Goal

Demonstrate the ability to design AI-assisted software delivery
controls and apply them to engineer, test, and document a
working customer-facing REST API.
